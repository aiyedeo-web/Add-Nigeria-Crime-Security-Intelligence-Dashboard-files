# Nigeria Crime & Security Intelligence Dashboard
## Project Overview
This project analyzes crime patterns, severity levels, and law enforcement effectiveness across Nigerian states.  
The dashboard provides insights into high-risk regions, dominant crime types, and case clearance performance to support data-driven security and policy decisions.
## Problem Statement
Crime data in Nigeria is often fragmented and difficult to interpret at a national and state level.  
This project aims to transform raw crime data into actionable insights that highlight risk concentration, enforcement effectiveness, and crime severity trends.
## Key Analyses & Insights
- Identified top 10 states by reported crime, with Lagos recording the highest volume  
- Analyzed cleared vs uncleared cases to assess law enforcement effectiveness  
- Found that banditry and kidnapping are the most prevalent crime types  
- Discovered that 32.5% of crimes are high severity, posing significant security risks  
- Highlighted uneven clearance rates across states, indicating capacity gaps  
## Impact
This dashboard enables stakeholders to:
- Prioritize high-risk regions  
- Focus resources on high-severity crimes  
- Improve law enforcement performance monitoring  
## Tools Used
- Power BI (Data modeling & dashboard design)  
- Microsoft Excel (Data cleaning & preprocessing)  
- DAX (Calculated measures and KPIs)  
- Data visualization & storytelling techniques
